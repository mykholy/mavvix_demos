# First-fold sales storytelling and unique page art direction — 8 verticals

These are ready-to-author creative briefs. Each must be built into actual responsive code; never use this document as a substitute for the pages. Arabic and English copy may be refined for the fictional brand but must retain specific industry purchase intent.

## 01. CONSTRUCTION
**AR hero line:** «المشروع القوي يبدأ بتفاصيل واضحة»
**EN hero line:** Build quality starts with a clear scope.
**Fold blueprint:** Full-bleed warm architectural interior, 38% copy overlay on charcoal panel, vertical numbered project carousel; project facts inset lower left.
**Above-fold first CTA flow:** Explore 12 concept projects → filter by service → view the tender scope builder.
**Concrete selling evidence:** دراسة نطاق المشروع + عرض عناصر التسليم + Gallery بمقاسات حقيقية توضيحية.
**Screen choreography:** first fold → value proof tied to data → browse/filter actionable records → deep detail → authentic CTA → honest receipt; on mobile hero remains readable without relying on landscape video.
**Screenshot requirement:** desktop and mobile hero, a deep detail page, functional interaction state; make hero distinguishable from other seven without its logo.
