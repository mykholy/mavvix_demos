# Mavvix Showcase — sell the experience without overstating what exists

## Homepage architecture
1. Headline: «شوف موقع مناسب لنشاطك قبل ما تطلب تنفيذه» / "Explore a website concept made for your industry".
2. Interactive industry filter: Construction, Manufacturing/Export, Real Estate, Healthcare, Ecommerce, Portfolio, Restaurant, Academy. Cards contain actual browser screenshots of built sites (desktop + mobile), distinct brand/palette, sub-sector tags, functional flow examples and a demo link. Never placeholder stock images represented as screenshots.
3. Side-by-side “what you can try” cards per vertical: e.g. Industrial compare SKUs and submit RFQ, Real Estate compare homes and request viewing, Academy try a lesson quiz. These are links into actual running routes, not video only.
4. Sector details page: 3 screenshots, features demonstrable now, one guided sales walkthrough, content requirements, example scope and estimated starting price if approved, exclusions, Arabic/English availability, desktop/mobile experience, real Mavvix sales CTA.
5. Before contacting sales let visitor explore at least one meaningful primary journey. Sticky CTA subtle on mobile; original site content not obscured.
6. Real sales link from env verified by owner; contact actual Mavvix (not fictional business), prefill the selected demo name only. No integration with customer's Facebook/Meta accounts necessary.
7. Distinguish "Concept demonstration" and genuine customer case studies. No fake clients, unsupported scores, testimonials or sales results. Demo content examples and transaction outcomes visibly marked.
8. Prevent indexing of eight fictional concept demo sites, but allow public Showcase and commercial sector description pages to be indexed.

## Paid ad capture guide
3 tested offers after first three demos are complete: Construction project gallery, Industrial product catalog+RFQ, Real Estate property experience. Use clips of actual browser interactions with real screenshot provenance. No claim an ROI was achieved. Message: "شوف التصميم والتجربة قبل ما تختار موقعك". Basic site price is not an offer of full production CMS if not included in contract; make scope explicit.

## Prospect qualification
Ask sector, number of pages/items, AR/EN need, CMS need, domain, asset availability, priority feature, content writing, planned budget. Mavvix quotes **scoped product** not automatic clone of full 8-demo preview. Keep pricing display optional and configurable, not hardcoded into demo brand.

## Advertising asset pack (created AFTER tested code)
Per vertical: 15-second vertical UI walkthrough, 9:16 and 4:5 mobile views, 16:9 desktop shot, 3 genuine feature screenshots, Arabic headlines/two variants, one direct CTA; captions reflect what the code currently supports. Creative images and screenshots have separate rights/provenance manifest.
